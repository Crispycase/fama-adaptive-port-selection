# Adaptive Port Selection for Fluid Antenna Multiple Access (FAMA) using 1D CNN-DQN

## Overview
This repository contains the implementation of an intelligent port selection mechanism for 6G Fluid Antenna Systems (FAS) and Fluid Antenna Multiple Access (FAMA). By leveraging Deep Reinforcement Learning (DRL), specifically a 1D Convolutional Neural Network (CNN) combined with a Deep Q-Network (DQN), this project aims to autonomously optimize antenna port configurations to maximize channel capacity and minimize interference.

## Key Features
* **6G Fluid Antenna Simulation:** Models the spatial flexibility of fluid antennas in a multi-user environment.
* **Deep Reinforcement Learning:** Utilizes a 1D CNN-DQN architecture for dynamic, real-time port selection without requiring exhaustive search.
* **Performance Analysis:** Evaluates the system's capacity, convergence rate, and stability compared to traditional fixed-antenna and baseline FAS selection methods.

## Technologies Used
